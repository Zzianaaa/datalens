# DataLens 数据分析助手

当前版本 0.12.0。无需模型 API 即可使用规则演示、任意 CSV 的手动 SQL 查询、结果导出和分析历史。

上传 CSV，用中文问题生成只读 SQL，并展示可核对的表格、图表和实际执行查询。

## 启动
需要 pnpm 11.25.0、Python 3.11+、Node.js 20.19+ 或 22.12+。

```sh
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cd frontend
pnpm install --frozen-lockfile
pnpm run build
cd ..
uvicorn backend.app:app --host 127.0.0.1 --port 8000
```

浏览器打开 http://127.0.0.1:8000 。点击「加载示例数据」，再点击「开始分析」。开发时可分别运行 uvicorn 和 frontend 下的 pnpm run dev。

## 三种模式
- 规则演示：无需密钥，仅支持界面列出的四个问题，要求相应的示例字段。不是模型推理。
- SQL 查询：支持任意上传的 CSV，表名为 data。中文或带空格的字段用双引号包围。实际 SQL 仍经过相同的只读校验。
- AI 自由提问：服务启动前设置 LLM_API_KEY、LLM_MODEL，可选 LLM_BASE_URL。使用兼容 Chat Completions 的服务。未配置时禁用。字段名称、类型和问题发送给模型，原始行数据不发送。真实模型集成尚未进行在线验收。

金额字段 amount 代表每条记录的总金额。销售额演示排除 returned 和 cancelled，仅统计 completed。演示数据是虚构订单，每行代表一个订单。

## 第二版使用体验
- 导出当前查询结果为 CSV，文本中的电子表格公式前缀会转义。
- 最近 8 次成功查询保存在当前页面，点击历史可切换结果。刷新或切换数据后历史清空。
- 当前数据标识保存在浏览器 localStorage，刷新可恢复未过期的数据。数据行仍只在服务器内存中。
- 移除当前数据可以提前释放服务器内存。
- 模型配置说明可在界面查看，密钥必须通过服务端环境变量配置。

## 架构与边界
Vue 3 + ECharts → FastAPI → 规则解析 / 模型生成 SQL → SQLGlot 语法树校验 → 子进程中的 DuckDB → 表格与图表。

单进程服务为本地演示设计，无登录或多租户隔离；项目、报告、目标、任务和库存保存到本地 SQLite。临时分析数据在内存中。数据使用随机标识，在内存中最多保存一小时；服务重启丢失。数据标识仅供本地演示恢复，不能替代用户身份验证。最多 10 份数据、每份 5 MB、20000 行、50 列。仅允许当前 data 表、单条 SELECT、白名单函数；第一版不支持连接、子查询、CTE 和窗口函数。子进程设置查询超时，DuckDB 限制 128MB 数据库内存与单线程，禁用外部访问。128MB 不是整个进程的操作系统内存限制。结果最多 200 行。

SQL 通过校验不代表统计语义正确。请核对筛选条件、字段和金额含义。数值直接来自数据库，不由模型自由生成。

## 面试讲解
1. 为什么不用模型直接算数字？数据库可提供确定性计算，SQL 也便于复核。
2. 为什么既校验 SQL 又关闭外部访问？语法校验与数据库能力限制形成两层防护。
3. 为什么保留规则模式？降低首次演示门槛，明确功能边界，并提供稳定回归用例。
4. 下一步：真实模型评测、查询修复、字段映射、测试更多 CSV 边界、用户身份与持久化。

项目处于第一版。简历中只写实际实现与验证的功能，不写尚未测得的准确率或生产规模。

## 第三版功能

- 数据质量报告：缺失率、完全重复行、不同值数量、前五个高频值和数值的最小/最大/平均/中位数。统计不会修改原始数据。
- SQL 模板：预览、行数、数值汇总、分组计数和分组汇总；可以选择数值字段和分组字段，查询执行前仍能修改 SQL。
- 图表 PNG 导出：两列且第二列为数值的结果支持柱状图、折线图及图片下载。

## 第四版功能

- 数据浏览：每页 20 行，任意字段字面搜索，按字段数值或文字排序，缺失值排在最后。搜索仅影响预览，分析 SQL 使用完整数据。
- 多列图表：选择分类字段和数值字段，支持柱状图、折线图和饼图。图表最多显示前 50 条非空数值；饼图拒绝负数。结果表及导出最多 200 行。
- HTML 分析报告：离线打开查看问题、实际执行 SQL 和结果表；数据中的 HTML 转义后展示。
- 质量报告 CSV：导出字段统计，字符串中的表格公式前缀经过转义。
- 查询结果标题固定为实际提交的问题，编辑输入不会改变旧结果标题。
- 错误与下载提示、可点击侧边导航、重复上传相同文件、图表资源释放及浏览请求竞态处理。
- ECharts 使用组件导入，将压缩脚本体积从约 455 KB 减至 262 KB。

### 页面使用路径

1. 上传 CSV 或加载示例，使用数据浏览检查搜索和排序。
2. 打开质量报告检查缺失值和重复行。
3. 进入 SQL 模式选择字段和模板，核对 SQL 后运行。
4. 选择图表字段及样式，导出 CSV、PNG 或 HTML 报告。

本项目仍为单用户本地演示，未实现账号系统和共享服务部署。

## 第五版：经营数据分析工作流

同一份 CSV 串联数据质量、清洗、经营看板、自由 SQL 和报告导出，没有加入与数据分析无关的求职工具。

1. 检查缺失、重复和字段类型。
2. 预览清洗：去首尾空格、去完全重复行、移除含缺失值的整行。应用时生成新数据副本，原始数据保留，可在有效期内撤回；刷新页面也可恢复原始数据引用。
3. 映射金额、类别、日期、状态字段，明确状态筛选值后计算经营指标。
4. 查看金额合计、记录数、有效金额记录平均值、类别前 20 排名和月度趋势，导出经营 HTML 报告。
5. 用 SQL 继续验证指标或深入分析。

示例中只筛选 completed 记录得到金额 805、8 条记录；全部状态金额为 885。金额按每行值求和，不再乘数量。记录数不是唯一订单数，平均金额不是按订单 ID 计算的客单价。

月度趋势支持 ISO 日期（如 2026-01-05）；无效日期仍计入总金额，但不计入月度趋势。

清洗副本与原始数据都只保存在服务内存，服务重启会丢失；最多 10 份数据。当前是单用户本地产品原型。

## 第六版：模块化经营平台

- 项目与数据中心：创建业务项目、保存当前 CSV 快照、按项目筛选、归档与恢复、重新打开分析。
- 本地持久化：项目、数据快照和保存的报告写入 storage/platform.sqlite，服务重启后仍保留。可用 DATALENS_DB 指定文件；复制该数据库前先停止服务。数据库被 Git 忽略，也不会放入项目交付 ZIP。
- 报告中心：保存当前查询的问题、SQL、结果和项目归属；保存报告不会随着源数据变化，支持离线 HTML 下载。
- 经营测算工具：单价、单位变动成本、固定成本、销量测算收入、利润与盈亏平衡销量。最多对比本次 10 个方案，导出 CSV。方案仅在页面内存中保存。

数据中心最多 50 项目、100 数据快照（总计 100 MB）、100 报告（每份 2 MB）。分析会话仍为最多 10 份、1 小时的内存缓存；保存的数据可随时重新打开。当前平台为本机单用户应用，无账号和公网共享权限。

## 第七版：第四大类「业务目标与任务中心」

- 业务目标：关联项目，记录目标值、当前值、单位和截止日期，显示完成百分比。当前值由用户更新，只支持越高越好的正数目标。
- 执行任务：记录项目、负责人、截止日期及执行说明，待处理/进行中/已完成/已归档状态流转。
- 管理视图：按项目筛选、逾期提示、统计卡片、归档恢复和任务 CSV 导出。
- 目标与任务保存在同一个 SQLite 数据库，刷新及服务重启后保留。最多 100 目标、500 任务。

负责人只作为文本记录，不发送邀请或通知。目标进度尚未自动连接分析指标。

## 第八版：库存与补货中心
- 新增商品 SKU、名称、计量单位和补货阈值，初始库存为零。
- 记录整数单位的入库、出库及业务原因，库存和流水在同一事务中保存；库存不足时拒绝出库。
- 搜索商品、筛选低库存，导出库存 CSV；建议补货量为补货阈值减当前库存，最低为零。
- 最近 100 条流水可查看，全部流水留存在数据库。错账用相反方向流水更正。
- 当前不计算采购成本、不预测需求、不自动扣减销售库存，也不向供应商下单。
- 数据库及用户数据不纳入 GitHub 或项目发布包。

## 第九版：采购与到货流程
每张采购单记录一个商品、供应商和整数订购数量。创建采购单不改变库存，分批登记到货时同步更新已到货数量、库存和入库流水。超额到货会被拒绝；完成后关闭到货操作。取消只关闭未到货部分，已到货库存保留。到货标识防止同一请求重试时重复入库。最多保存 500 张采购单，尚无采购金额、供应商接口或自动下单。

新版本启动前需重启后端服务。

## 第十版：经营预警中心
库存、采购、任务和目标集中展示，支持类别筛选、CSV 导出及跳转处理。库存补货缺口考虑待到货量；零库存优先级高。任务逾期排除已完成、已归档状态；截止日期等于今天尚不视为逾期。目标到期未达标依据手工填写的当前值。待到货采购只提示安排交付，不判断采购逾期。

日期使用浏览器本地日期，进入或刷新预警页时读取最新状态；没有后台监控或自动通知，也不使用模型判断。

## 第十一版：指标模板库
保存名称、业务口径与只读 SQL，可搜索并应用到当前分析数据。应用仅填入工作台，核对字段后再执行；切换 CSV 或快照可复用同一 SQL，字段不兼容会报错。可复制工作台当前 SQL，最多保存 100 个模板。定义持久化到本地 SQLite，不保存数据行，未接模型。

指标模板支持归档与恢复：默认隐藏旧模板，开启“显示归档模板”可恢复，归档模板不能直接应用。旧版本数据库自动增加归档字段并保留原定义。

## 第十二版：回款与账龄中心
手工应收台账，记录唯一单据号、客户、金额和截止日期，支持分次回款、重复请求保护、超收拒绝、逾期筛选、账龄分类及 CSV 导出。统一以元展示，以整数分保存，最多 500 条应收记录。并非银行或会计系统，不支持多币种、实际退款或自动对账。

回款纠错支持整笔冲销：填写原因，撤回已收金额并保留原流水及冲销说明。相同请求不会重复扣减。重新登记正确回款即可完成纠错；该操作不代表实际退款。

客户回款汇总按完整客户名称分组，展示应收、已收、未收、逾期与回款率，按逾期未收优先排序，支持查看该客户单据和五档账龄分布。截止日当天未逾期；结清单据未收为零，冲销后实时纳入余额。

客户汇总可安排回款跟进任务，填写负责人和截止日期后跳转任务中心。同一客户未完成任务会复用，不重复创建；任务金额为创建时快照，回款后需手工完成。

### 采购交期

创建采购单时可填写预计到货日期。经营预警按所选日期判断：预计到货日早于当天、仍有未到货数量的采购单为高优先级；当天、未来或未设置日期时保留普通待到货提示。分批收货保留剩余提醒，收齐或取消后解除采购提醒。旧数据库自动添加空日期字段，已有库存、采购和流水保留。

### 销售订单与履约

新增销售业务模块：创建最多 20 种商品的销售订单，搜索、按状态筛选及导出台账。待发货订单不预占库存；可分批发货，每批在同一个数据库事务中按实际发出数量扣减库存、生成出库流水和该批应收单据。库存不足、应收编号冲突或容量不足时整笔操作回滚，重试已发货订单不会重复登记。待发货和部分发货订单可关闭未发余量，已发商品、应收和回款保留。已发完订单不能取消，暂不支持退货。

单价、应收及回款以整数分保存。看板分别显示待发货单量、已发货金额与未收金额；回款台账登记或冲销后，销售模块刷新显示最新已收金额。单价不含税费、运费、折扣，发货金额不代表收入确认或现金到账。

### 经营平台总览

总览以同一个数据库读取快照汇总销售、回款、库存、采购、任务和项目资产；提供业务处理入口及优先回款客户。按浏览器本地日期判断逾期，截止当天不逾期。金额均为全部历史台账累计值；已收包含手工应收和销售应收，发货金额只统计已发货销售订单，不能用两者相减推导未收。不同商品数量不混合累计，CSV 分析数据不自动写入经营台账。

### 供应商应付与付款

采购单可填写单价和付款截止日期；每批登记到货时，库存、到货流水和对应应付在同一个事务中保存。应付按本批到货数量 × 单价计算，取消剩余采购不删除已到货应付。旧采购成本显示“未填写”，不自动估算或补记金额。

应付中心支持分次付款、供应商余额汇总、逾期筛选、CSV 导出和误录付款冲销。付款请求及到货请求均有重复请求保护；超过未付金额、容量上限时拦截并回滚。付款只是手工台账，不发起银行转账；不支持采购退货、预付款和税费折扣。付款逾期连接经营预警，已付/未付同步经营总览。

### 经营费用与收付核对

记录已支付的租金、人员、营销、物流、软件、办公及其他经营费用，可关联项目，按月份、类别、项目与说明筛选，查看费用结构和月汇总，导出明细 CSV。误录费用作废后保留原金额与原因，从有效合计中扣除。

总览台账收付净额 = 已收回款 − 供应商已付 − 有效经营费用。该数值不包含期初余额、未登记支出，也不等同于利润或银行余额。供应商采购付款在应付模块登记，同笔支出不要再次登记为经营费用。

### 月度费用预算

费用台账支持按月份、类别设置正数预算限额，同一组合再次保存会更新。预算实际值按该月份的有效费用计算，作废费用自动剔除；没有设置预算的类别不判断超支。经营预警仅检查浏览器当前月份，实际金额严格大于预算时提示；达到预算但未超过不触发。

### 多商品、分批履约与升级兼容

订单台账显示各商品订购/已发/未发数量、订单金额、实际发货金额及跨批次已收合计。每批应收独立登记回款；同一批次重试不会重复出库或产生应收，重复商品行与超量发货会拦截。发完剩余商品时，任何一行库存不足都会整批回滚。

旧单商品订单自动补齐明细，保留原流水、应收和已收金额，不重新扣库存或补记应收。经营总览按实际已发明细汇总，部分履约或关闭余量的订单都不会漏计已发金额。

### 销售履约缺货与补货

销售页汇总每个商品全部待发货/部分发货订单的未发需求、现有库存、当前缺货、采购待到货和采购缺口。当前缺货 = max(未发需求−库存,0)，采购缺口 = max(当前缺货−待到货,0)。商品不跨单位合计，库存不预占，待到货不能立即发货。

缺货进入经营预警，可打开库存采购或查看待履约订单。收到采购后重新核对库存，关闭未发余量后自动移除相关需求；完成或关闭订单不再计入需求。

### 发货批次对账

销售页可查看每批商品明细、应收金额、有效回款、冲销记录及出库流水，并导出明细 CSV。对账使用同一个读取快照，检查商品金额与应收金额、有效回款与已收余额，以及每行出库数量和商品是否匹配。发现差异只提示，不自动改写台账。

新批次在发货事务中保存精确的库存流水关联；升级前的批次显示“历史批次库存未关联”，不根据时间、数量或说明猜测流水。对账仅核对本平台记录，不代表银行到账确认。

### 库存流水核对

库存页按全部历史出入库流水净额核对现量，显示流水条数和数量差异；所有商品从零库存建立。最近流水仅显示 100 条，核对仍使用全部记录。读取同一个数据库快照，差异进入经营预警的“对账”类别，可打开库存查看；不会自动修改库存，也不代表实物盘点。

### 月度经营收支

总览显示截至所选统计日期的近 12 个月有效回款、供应商付款、经营费用和台账净额，空月份补零并支持 CSV 导出。回款和付款按登记时间 UTC 日期分月，费用按发生日期分月；已冲销和作废记录从原月份剔除，历史数值会随更正更新。净额不代表利润或银行余额。

### 供应商采购安排

库存采购页按供应商精确分组全部未完成采购，显示待到货/逾期/未设交期单量、最早交期及逐商品剩余数量。剩余已知成本按未到货数量乘已填写单价计算，未填写成本单量单列，不等同于供应商应付余额。可筛选该供应商采购单和导出汇总 CSV，不跨商品或单位合计数量。

### 收付流水核对预警

经营预警页按全部未冲销回款和供应商付款流水核对应收/应付已收/已付余额，并检查余额及有效流水是否在单据总额范围内。显示检查单量和异常数，异常进入“对账”并提供回款或供应商付款入口。只读核对，不自动改写记录，不验证银行到账。

### 收付款到期安排

总览按统计日期将未结清应收/应付分为已逾期、今天到期、未来 1–7 天、未来 8–30 天及 30 天以后，显示单量和剩余金额，支持 CSV 导出和对应台账处理入口。区间互不重叠，分次收付、冲销后重新计算。待到货采购不形成应付；应收不保证按期到账，不抵扣应付推算可用资金。

### 采购交期跟进任务

未完成采购可一键创建业务任务，记录供应商、商品、剩余数量与交期快照，任务截止沿用采购交期，未设置时保留空日期。重复点击复用同一采购单未完成任务；完成/归档后可重新建立最新快照。到货、取消采购不自动完成任务，负责人在业务任务页设置。关闭或收齐采购不再创建跟进任务。

### 项目费用投入

费用页按项目标识汇总有效经营费用，显示金额、笔数、类别及首笔/最近日期，支持月份筛选、CSV 导出和对应费用明细筛选。未关联项目单列，同名项目不合并；汇总仅受月份影响，不受明细搜索/类别/项目筛选影响。作废记录剔除，不包含采购付款、应付或未登记成本，不代表项目利润。

### 销售客户履约汇总

销售页按客户名称精确汇总全部订单的待履约/部分发货/关闭余量单量、原订单金额、实际发货、销售已收及未收金额，支持客户订单筛选和 CSV 导出。原订单金额包含已关闭未发余量，实际发货与回款保留；不包含手工应收，不自动合并客户别名。客户汇总不受订单搜索和状态筛选影响。

### 到期前收付提醒

经营预警按浏览器统计日期提醒未结清回款与供应商付款：已逾期为高、今天到期为中、未来 1–7 天为提示，第 8 天及之后不显示到期提醒。结清解除，冲销恢复余额后重新出现。支持类别和优先级交叉筛选及筛选结果 CSV 导出；只在读取页面时计算，不发送通知或执行转账。

### 供应商付款安排任务

未结清应付可创建业务任务，保留供应商、商品、余额和截止日期快照；重复点击复用该应付的未完成任务，任务完成或归档后可创建新快照。任务不执行转账，付款或冲销不自动更新任务状态，已结清单据禁止新建；可直接打开业务任务设置负责人。

### 任务执行筛选

业务任务支持项目、精确负责人、截止状态及任务/负责人/说明搜索的交叉筛选，未填写负责人单列。逾期、今天到期和无截止日期仅检查未完成/未归档任务。看板计数及 CSV 导出与筛选一致，重置恢复默认；目标进度仅受项目筛选影响。

补货覆盖计划按商品标识合并未关闭采购剩余量，分别显示现货缺口、待到货、逾期/未设交期数量和净追加量，可导出 CSV 和准备采购表单。逾期待到货仍计入覆盖，需自行跟进；计划不包含预测或销售预占，不改变可发货库存。准备采购不会保存订单。

采购明细支持供应商、状态（含部分到货）、交期及关键词组合筛选，可导出当前采购明细。交期仅检查未关闭剩余量，取消采购的待到货导出为零；不影响全量供应商与补货汇总。

收款方支出汇总按精确名称和月份聚合有效经营费用，未填写单列，可导出并筛选明细。汇总不受明细搜索/项目/类别影响；切换项目核对清除收款方筛选，重置恢复全部有效明细。不含采购付款。

月度预算执行核对可选择月份，逐类别显示预算、实际、剩余或超支和使用率，包括未设预算及零支出类别。统计全量有效费用，独立于明细筛选；可导出并跳转月份/类别明细。

预算核对清空月份时停止计算并提示选择月份，不将未选月份解释为零支出。

预算执行表新增设置/调整预算入口，只填入上方预算表单的月份、类别和已有限额；未设预算清空金额，需填写后保存。点击准备不会写入数据库。

未完成任务预警覆盖逾期（高）、今天到期（中）和未来七天（提示），完成/归档后解除；未设日期和七天外不提醒，可进入业务任务中心处理。

未达标业务目标增加当天到期与未来七天提醒，达标后解除；进度来自手工登记，不自动推断目标完成。

预警清单支持类别、优先级和关键词组合搜索，可搜索事项说明中的客户、供应商和负责人，一键重置；导出当前结果，顶部计数仍为全量。

数据中心保存项目、快照与报告时通过数据库写事务保护容量检查，避免并发保存突破项目数、快照数或报告数上限。
