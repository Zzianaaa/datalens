# 部署与域名

本页说明如何把现有 DataLens 运行方式迁移到服务器，不代表线上服务已经开通。当前没有已配置的应用域名，也没有中国大陆网络的可达性实测结果。

## 先确定使用范围

- **个人真实业务**：继续本机运行，或在有访问控制的私人服务器运行。数据库保存在自己的磁盘。
- **公开演示**：使用独立实例，仅放虚构数据。现有应用没有账号隔离，访客会共享台账、操作权限和服务容量，不能放个人真实业务数据。
- **多人正式使用**：需要先完成身份、权限、用户数据隔离及运维方案；仅绑定域名不能解决这些问题。

## 中国大陆访问怎么选

| 方式 | 需要什么 | 需要核对的条件 |
| --- | --- | --- |
| 中国大陆服务器＋自定义域名 | 自有域名、服务器、HTTPS | 按服务商要求完成备案及接入；上线后实测多家运营商网络 |
| 香港等非大陆节点＋自定义域名 | 自有域名、服务器、HTTPS | 服务商对香港节点通常不要求 ICP 备案；跨境网络速度与可达性仍需实测 |
| 平台提供的免费二级域名 | 支持 Python 后端的平台账号 | 核对当期免费政策、持久磁盘、休眠、资源限制，以及大陆访问情况；不能承诺长期免费或稳定访问 |

域名本身不会改善网络线路；DNS 解析成功也不等于页面与 API 都能访问。没有域名或服务器时，不能凭空分配可控的自定义域名，也不能把本机 `127.0.0.1` 当作线上地址。

截至 2026-10-22，华为云官方说明：中国大陆资源需要按其流程备案，香港等非大陆资源不需要在其平台进行 ICP 备案。实际接入条件以选定服务商和网站用途为准。参考：[备案基础](https://support.huaweicloud.com/icp_faq/icp_05_0141.html)。

## 免费演示优先路径

用户当前选择：没有域名或服务器，优先使用平台免费演示地址。建议先在[魔搭创空间](https://modelscope.cn/studios)核对账号可用的 Docker 部署资格、免费额度与入口。它提供中国大陆平台入口，但实际应用发布、资源申请和大陆多网络访问仍需部署后验证；本文不承诺额度永久免费。

当前准备了通用 `Dockerfile`：构建现有前端，运行 Python 后端，默认端口 `7860`，可用 `PORT` 覆盖，单进程运行。`.dockerignore` 使用白名单，构建上下文排除本机数据库、密钥、Git 历史和备份。它是待平台构建验证的部署配置，本机没有 Docker 引擎，尚未完成镜像构建验收。

有 Docker 环境时可在仓库根目录验证：

```bash
docker build -t datalens-demo .
docker run --rm -p 7860:7860 datalens-demo
```

打开 `http://127.0.0.1:7860`。上述命令不挂载业务数据；容器删除后演示台账丢失。平台如要求不同端口，请设置 `PORT` 并匹配平台入口配置。不要上传本机 `storage/`。

目前魔搭入口尚未登录，需要账号所有者完成登录；若申请 Docker 空间时要求实名或关联阿里云账号，应由本人操作并核对免费资源条件。获得可用账号资源后才能创建空间、构建、分配真实访问地址，不能提前编造演示链接。

其他候选：Render 提供平台二级域名和免费 Web Service，但免费实例无持久磁盘，空闲后可能休眠；不能用于保留真实业务台账，也尚未验证其大陆可达性。参考：[免费服务说明](https://render.com/docs/free)、[Web Service 域名](https://render.com/docs/web-services)。

## 服务器部署步骤

1. 准备 Linux 服务器，安装 README 指定的 Python、Node.js 和 pnpm；下载代码并按快速启动步骤安装依赖、构建前端。
2. 为数据库创建独立持久目录，运行账号应有读写权限。启动前设置，例如：

   ```bash
   export DATALENS_DB=/srv/datalens-data/platform.sqlite
   uvicorn backend.app:app --host 127.0.0.1 --port 8000 --workers 1
   ```

   `/srv/datalens-data` 是需要自行创建并授权的示例目录。不要把存储放在临时容器文件系统，或当作前端静态资源发布。

3. 用服务管理器保持进程运行；通过 Nginx、Caddy 或托管平台的反向代理提供 HTTPS。页面与 `/api` 都转发到同一个后端。后端端口仅供代理访问。
4. 私人实例先在反向代理或网关配置访问认证，再开放入口；公开演示实例与真实数据实例使用不同数据库、环境和密钥。
5. 在域名 DNS 管理页面添加服务商要求的 A/AAAA 或 CNAME 记录；证书覆盖实际使用的域名。没有 IPv6 服务时不要添加不可达的 AAAA 记录。
6. 在中国大陆实际网络验证首页、静态资源、`/api/config`、虚构 CSV 上传/查询和页面刷新。使用虚构业务记录验证服务重启后持久化，再测试备份恢复。

应用内临时分析数据只在一个进程的内存中。不要通过增加 Uvicorn worker 或启动多副本来直接扩容，否则同一数据标识可能在不同请求中查不到。已保存快照可重新打开，但临时会话重启会失效。

## 费用与持久化

自定义域名通常涉及注册与续费；域名、服务器、磁盘等费用应先确认，不自动开通付费资源。已有资源可以复用，但仍需核对访问控制和数据保存方式。

不要仅因为平台提供免费地址就认为它适合业务台账。需先核对当前免费额度是否支持后端运行，以及休眠、重启和重新部署是否会清空磁盘。备份不上传代码仓库，也不使用公开数据集替代私人数据库备份。

## 当前待提供的信息

实际绑定域名需要：域名名称及 DNS 管理权限、目标服务器或托管项目、使用范围（私人业务或公开演示）。如果尚无资源，先选定预算和服务商；在获得可用资源前，本仓库不填写虚构的“在线体验”链接。
